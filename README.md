# SaM Virtual Machine

An interpreter for **SaM** (Stack Abstract Machine) assembly, written in Python. It reads a `.sam` program, executes it instruction by instruction and prints a trace with the stack state after every step, which makes it useful for studying and debugging code generated by compilers.

Built for the Compilers course of the B.Sc. in Computer Science at the Instituto Federal de Brasília (IFB), first semester of 2024. An extended version of this VM is used as the execution back end of my [Simple Fortran Compiler](https://github.com/vinyciussousa/simple-fortran-compiler).

## Features

- **Stack and memory:** `PUSHIMM`, `ADDSP`, `PUSHABS`, `STOREABS`, `PUSHOFF`, `STOREOFF`
- **Arithmetic:** `ADD`, `SUB`, `TIMES`, `DIV`, `MOD`
- **Logic:** `AND`, `OR`, `NOT`, `NAND`, `NOR`, `XOR`
- **Comparison:** `EQUAL`, `GREATER`, `LESS`, `CMP`, `ISNIL`, `ISPOS`, `ISNEG`
- **Control flow with labels:** `JUMP`, `JUMPC`, `JUMPIND`
- **Subroutines and stack frames:** `JSR`, `RST`, `LINK`, `UNLINK`, `POPFBR`, with a frame base register (FBR) for relative addressing
- **Program end:** `STOP` prints the value at the bottom of the stack (the program's result) and warns if values were left on the stack

## Usage

Requires Python 3 and no external dependencies.

```bash
python3 sam_vm.py examples/arithmetic.sam
```

Programs can contain comments (`// ...`) and labels (`LOOP:`), which are referenced by jump instructions (`JUMP LOOP`).

## Example

`examples/arithmetic.sam`:

```
// Computes (5 + 3) * 2 and leaves the result at address 0
PUSHIMM 5
PUSHIMM 3
ADD
PUSHIMM 2
TIMES
STOP
```

## Included examples

| File | What it shows | Result |
|---|---|---|
| `examples/arithmetic.sam` | Basic stack arithmetic | `16` |
| `examples/loop.sam` | Loop with labels and conditional jumps (sum of 1 to 5) | `15` |
| `examples/subroutine.sam` | Subroutine call with `LINK`, `JSR`, relative addressing and return via `JUMPIND` | `49` |

## How it works

1. Each line is parsed with a regular expression into an instruction and an optional operand. Comments and blank lines are skipped, and labels become markers in the instruction list.
2. The interpreter keeps a Python list as the stack, a program counter and the frame base register (FBR).
3. Jumps look up the target label in the instruction list. `JSR` pushes the return address so the subroutine can return with `JUMPIND` or `RST`.

## Known limitations

- Label names in jump operands must use uppercase letters, digits or hyphens.
- `PUSHIMM` accepts only integers, and `DIV` uses Python's true division (`7 / 2` gives `3.5`). Floating-point and output instructions (`PUSHIMMF`, `ADDF`, `WRITE`, `WRITEF`, …) exist only in the extended version used by the [Simple Fortran Compiler](https://github.com/vinyciussousa/simple-fortran-compiler).
- There is no validation of malformed programs: an unknown label or an empty stack raises a Python error.
